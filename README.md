# San14 Co-op plugin

《三国志 14 威力加强版》双客户端、双势力联机研究原型。目标是两名玩家各自操作自己的势力，地图上的其他势力继续由 AI 控制。

当前有房间协议、指令同步原型、势力视角转换和若干通过实机验证的原生接入模块，**尚未形成可直接开玩的完整双人版本**。

## 给接手的 AI / 开发者

1. 从 [当前交接](docs/HANDOFF.md) 开始：已完成什么、缺什么、下一步怎么做。
2. 阅读 [整体设计](docs/ARCHITECTURE.md) 和 [换电脑配置](docs/LOCAL_SETUP.md)。
3. 从 [离线检查工具](tools/README.md) 的无实机测试入手，不要直接执行历史注入脚本。
4. 每次实质进展更新交接文档、验证、提交并推送。具体规则见 [AGENTS.md](AGENTS.md)。

内政功能具体覆盖和不操作游戏也能推进的工作，见[内政同步盘点](docs/DOMESTIC_SYNC_STATUS.md)。其中明确区分草稿读取、单游戏执行与真正双端同步。

当前主线按三部分推进：

- 房间与指令：赏赐已接同一User/Save所有者和实际TLS；完整房间身份、旬末日期和两期诊断保存也已组合。真实菜单与两端数值刷新仍缺。
- A保存：首次实机产生新文件但收尾校验失败，修复待fresh进程验收。最新跨旬后继已在离线组合接通正常推演阶段、状态对象换址和第二次保存；真实推进与保存仍待验证。
- B加载：已有一次真实原生加载及刘备视角成功。warm后继已在同一自有进程完成两个独立模块对同六槽的接管；文件暂存与本代身份采样也已分别验证。仍需统一启动接线、两份合法新档和连续实机加载。

精确证据和下一步以[当前交接](docs/HANDOFF.md)为准；[首轮双机清单](docs/FIRST_TWO_PC_TEST.md)只要求固定34号档连续两旬、不下新命令，尚未达到开测条件。完整内政和严格战斗锁步可在基础闭环之后推进。

## 最近的实机里程碑

2026-10-08：在一个真实游戏进程中启用张鲁、刘备的双人势力规则并推进一旬。四类 AI 入口共 120 次调用，8 次按玩家势力规则跳过，112 次执行原生处理；1,044 次收入归属判断均返回，没有活动调用、挂起或异常残留。六处补丁已撤回，用户已恢复测试存档。

这是一份游戏连接两个本机诊断席位的测试，尚非两台电脑各运行一份游戏。收入判断比纯转发基线多 348 次，来源及实际经济数值仍需对照。[验证摘要](docs/evidence/2026-10-08-human-rules.json)

## 目录

| 路径 | 用途 |
